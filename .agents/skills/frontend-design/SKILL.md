# Frontend Design Skill

Eight anchors. Each is a distinct aesthetic territory locked to specific CSS tokens. Pick one per brief. Match its tokens.

> **Reach for the unexpected. Fidelity to the anchor. Discipline on the content. Nothing left to default.**

---

## 1. How to work

Before writing code, run this sequence:

1. **Context** — Identify purpose, audience, domain, content density. State the problem in one sentence.
2. **Anchor** — Pick one: Swiss, Industrial, Brutalist, Aurora, Chaotic, Retro-Futuristic, Organic, Lo-Fi. State the choice and the reason in one line.
3. **Differentiator** — Define one memorable anchor-internal move: a signature interaction, typographic gesture, or visual motif.
4. **System** — Match the chosen anchor's tokens exactly.
5. **Implementation** — Outline structure, then build. Content on screen is real and disciplined — no fabrication, no filler labels.

---

## 2. Content Discipline

- **No fake telemetry or filler labels**: Avoid invented status strings or meaningless mono-caps subtitles.
- **Standard UI copy**: Use standard, clear labels for standard actions (`Next`, `Save`, `Sign In`).
- **Clean iconography**: Use established icon libraries or SVG vector icons instead of unicode glyph hacks.

---

## 3. The Eight Aesthetic Anchors

1. **Swiss**: Clean white/neutral surfaces (`#FFFFFF`, `#F7F7F8`), strong sans-serif typography, asymmetric grid layouts, deliberate single accent color (`#E4002B` or `#002FA7`).
2. **Industrial**: High contrast dark surfaces (`#000000`, `#0B0C0A`), monospaced typography (IBM Plex Mono, JetBrains Mono), crisp 1px borders, high-visibility signal accents (`#00E676`, `#C6FF4A`).
3. **Brutalist**: Raw layout structure, bold high-contrast borders, stark typography, unpolished layout lines, high contrast color blocks.
4. **Aurora**: Soft radiant gradients, frosted glassmorphism, subtle backdrop blurs, luminous accent highlights, smooth rounded containers.
5. **Chaotic**: Expressive typography, overlapping layout layers, dynamic angled cards, energetic color pop.
6. **Retro-Futuristic**: Cyberpunk/synthwave aesthetics, neon vector strokes, dark glowing surfaces, scanlines and grid patterns.
7. **Organic**: Earthy tactile tones, warm paper surfaces, elegant serif/sans pairings, soft rounded corners, smooth micro-interactions.
8. **Lo-Fi**: Minimalist monochrome, subtle paper textures, quiet typography, restrained layout density.
